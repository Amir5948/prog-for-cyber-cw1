#Overview This repository contains my coursework 1 porifolio. It holds 5 python programs which applies security ideas such as authentication, password checks, input validation etc. The main branch is the overview. Each of these python programs has its own branch with the code, a readme file and screenshots of the test runs.
#Programs 1: Security tool: A program which is like a menu and the user must log in first. It includes a security event counter, brute force simulation, login authentication and the ability to exit the program. 2: Security Event logger: This program records security activities so they can be reviewed, it records their event ID, username, IP address, result and the timestamp to check for suspicious activity 3:: IP Address Validator: This program checks if the IP address entered by the user has a valid format and displays whether its valid 4: Security Incident Manager: This program stores and updates certain details of a security incident such as username, IP address, event type, risk level and displays the information 5: Reusable Cyber security utilities using user defined modules: A reusable program of security functions such as validating passwords and IP addresses and generating strong random passwords
