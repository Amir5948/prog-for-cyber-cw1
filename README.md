# What the Program Does
This program is a basic security tool. The user must log in first. After logging in, they are shown a security menu with these options:
1. Security Event Counter – asks for a password 10 times, counts correct and incorrect attempts, shows the percentage of incorrect attempts and raises an alert if it is more than 50%.
2. Brute-Force Simulation – lets the user guess a password until it is correct or the maximum number of attempts is reached.
3. Login Authentication – asks for a username and password and allows three failed logins before displaying that the account is frozen for 24 hours.
4. Exit – displays "Thank you for using the security tool" and ends the program.

The program keeps running until the user chooses Exit.
