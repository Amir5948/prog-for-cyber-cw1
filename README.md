## Overview
This repository contains my Coursework 1 portfolio. It holds 5 Python programs which apply security ideas such as authentication, password checks and input validation.

The main branch is the overview. Each Python program has its own branch containing the code, a README file and screenshots of the test runs.

## Programs

### 1. Security Tool
A menu-based program where the user must log in first. It includes a security event counter, a brute-force simulation, login authentication and the ability to exit the program.

### 2. Security Event Logger
This program records security activities so they can be reviewed. It records the event ID, username, IP address, result and timestamp of each login attempt to help check for suspicious activity.

### 3. IP Address Validator
This program checks whether the IP address entered by the user has a valid format and displays whether it is valid.

### 4. Security Incident Manager
This program stores and updates details of a security incident, such as the username, IP address, event type and risk level, and displays the information.

### 5. Reusable Cyber Security Utilities using User-Defined Modules
A reusable module of security functions for validating passwords and IP addresses and generating strong random passwords.
