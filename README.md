# What the Program Does
This program stores and updates information about a security incident using a dictionary.

The program:
- Creates a dictionary containing a username, IP address, event type and risk level
- Displays the username and IP address
- Adds a new field called status
- Updates the risk level
- Removes the event type field from the dictionary
- Displays all the remaining keys and values
- Displays the total number of key value pairs

# How to Run
1. Open a terminal in this folder.
2. Run:
   python security_incident_manager.py
3. The program does not require any input
